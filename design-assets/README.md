# Stuck in a Pickle asset archive

The skeptical pickle character artwork is intentionally retained here as a future brand asset. It is not part of a shop or merchandise pitch in the first version of the publication.

- `favicon-source.png` is the full-resolution character source used for the small site icon.
- `og-source.png` is the original social-card artwork.
- `stuck-in-a-pickle-logo-source.png` is the current full-resolution publication logo with the intentionally indefinite “EST. 202X” date.
- `stuck-in-a-pickle-logo-with-date.png` preserves the earlier “EST. 2024” version.
- `stuck-in-a-pickle-logo-without-date.png` preserves the version with the date ornament removed.
- `stuck-in-a-pickle-logo-transparent.png` is the supplied transparent masthead used on the site.
- `pickle-jar-character.png` is the supplied transparent standalone character used in the footer.

If print-on-demand is explored later, start from these source files rather than the compressed public assets.
